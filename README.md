# 宠物大冒险 🐱🛵

一个 9 岁小朋友用 AI 做出来的游戏：宠物 + 载具 + 6 大主题随机关卡 + 收集礼物，横版跑酷平台跳跃。
**在线玩**：<https://chillsann.github.io/pet-adventure/>（推送 main 后自动生效）

## 最新改动

### 紧急修复：选角色卡关 + 通关卡死（2026-09-10）

玩家实测反馈两个致命问题，已定位根因并修复：

| # | 现象 | 根因 | 修复 |
|---|------|------|------|
| 1 | 主页选宠物后无法直接开始，只能走「每日挑战 → 开始挑战」 | 严格模式下 `questRuns` / `questGiftCount` 未声明就被赋值，抛 `ReferenceError` | 补上 `let questRuns` / `let questGiftCount` 声明 |
| 2 | 第 1 关通关领完礼物后卡住不动 | 上面的异常从 `tick()` 抛出，直接终止了 `requestAnimationFrame` 循环（这就是"卡死"） | 给 `step()` / `render()` 及外层 `frame()` 加 try/catch 兜底，单帧异常不再中断循环 |
| 3 | （回归测试发现）「免费道具」入口点了没反应 | 该按钮不在 `TAP_ACTIONS` 白名单里，pointerdown 不触发 | 移除白名单：除左右/跳跃需长按外，其余按钮一律 pointerdown 立即触发，并消费指针避免 pointerup 二次触发 |
| 4 | 礼物收集数未计入每日任务 `gift20` | 星星收集写的是 `window._questGiftCount`，结算读的是模块变量 | 统一改用模块变量 `questGiftCount++` |

> 附带修掉 3 处竖屏错位：封面段位信息被宠物网格遮挡、背包第 3 行被「返回」键盖住、toast 提示与 HUD 重叠。
> **自动回归全绿、0 未捕获异常**；竖屏 4 机型（375×667 / 390×844 / 412×915 / 430×932）全部正常。

### 借鉴《合成竞速之王》：金币经济 + 零件合成 + 离线收益（2026-09-10）

参考抖音小游戏《合成竞速之王》，把它最值钱的那条循环嫁接了过来 ——
**产出 → 购买 → 合成 → 变强 → 产出更快**，每一环都能在 3 秒内看到结果：

| # | 新增系统 | 说明 |
|---|---------|------|
| 1 | 金币经济 | 吃礼物实时 +金币（HUD 上的数字肉眼可见地跳），通关再按「得分 × 评价」结算一笔；金币只有一个消耗口，经济不会失控 |
| 2 | 零件合成 | 5 个部位（发动机/轮胎/悬挂/车架/氮气）× 6 级；两个同级零件 = 合出高一级，合成不花钱只花零件，让它成为纯粹的正反馈时刻 |
| 3 | 改装工坊 | 封面一级入口 + 「可合成」红点；买 / 合成 / 一键合成；5 个部位等级徽章 + 车库强度进度条，短板一眼可见 |
| 4 | 离线收益 | 「宠物快递站」离线也赚金币，每小时 120、上限 8 小时；回访主动弹提示，一键领取 |
| 5 | 零件真的变强 | 零件等级直接注入关卡载具（vmax/accel/jump），跳得更高、跑得更快、金币更多 —— 升级能"摸到"，闭环才算成立 |

平衡取舍：「离线 8 小时 ≈ 5 次通关的金币」是刻意压低的 —— 它是**回来的理由**，
但不能取代主动游玩，否则挂机就赢了，游戏也就死了。

**顺带修的问题**：菜单界面（工坊/背包等）渲染时底下的关卡世界和 HUD 会透上来糊成一团，
新增 `isMenuState()` 统一判定，让 HUD、虚拟按键、遮罩浓度都读它；菜单态背景加深到近乎不透明。
横屏下卡片原本画到屏幕外（横屏画布只有 506 高，宠物网格就吃满了），改成横屏放网格左侧、竖屏放网格下方。

### 深度优化：功夫熊猫风 + 道具系统 + 留存钩子（2026-09-08）

| # | 要求 | 实现 |
|---|------|------|
| 1 | 动物形象更可爱、功夫熊猫风 | 视觉放大 1.4×，Q 版大头身小比例，白描轮廓加粗，瞳孔更大带双高光，眨眼弧线微笑；着地 squash & stretch 弹性动画；受伤/开心/护盾气泡情绪表达 |
| 2 | 背景音乐缺失 | 4 层前瞻调度器（lead/pad/kick+snare+hat），6 首主题旋律+和弦+鼓组；音量从 1.6% 提升至 40%；音效库：coin/shoot/fall/exploit/open/sign/rank/quest/shield 共 9 种 |
| 3 | 通关礼物变为可用道具 | 9 种道具表（shield/magnet/boost/giftbox/balloon/heart/jetpack/turbo/cloud）；背包系统（3×3 格子）；下一关携带一件装备，`prepareRunItem()` 自动注入效果（护盾/磁铁/加速/车辆切换）；通关后必掉 1 件 + S 评价额外奖励 |
| 4 | 多类留存钩子（孩子+成人） | **签到系统**：7 天轮回奖励（积分/金币/道具）；**宝箱系统**：木质/银质/金质/钻石宝箱，冷却 60-1800s；**每日任务**：通关/集礼物/拿 S 评价等 4 类任务，完成后领道具；**免费道具**：看广告领稀有道具，30min 冷却；**段位系统**：青铜→王者 7 级，封面显示进度条；**总分累积**：本地持久化，段位随总分提升 |

> 设计取舍说明：「奥德赛级 3D」单靠 AI 在沙箱里做不出，且手机小游戏跑不动那个画质；
> 「2.5D 精致化」是性价比最高的方案（成本低/见效快/不推翻手绘/性能零压力）。
> 画风从来不是留人的关键——"羊了个羊"纯 2D 也爆了。真正能留住人的是玩法钩子和成长系统，已落地。

## 目录结构

```

├── index.html            # 游戏本体（单文件：内核 + 手绘角色库 + Web 适配层）

│   ├── e2e-kid-requests.mjs  # E2E：5 条意见验收（Playwright）
```

## 上传 GitHub（在本机有网的环境执行）

```bash
cd pet-adventure
git add index.html README.md tools/ docs/
git commit -m "小朋友的 5 条意见：一击死亡/新障碍/BGM/装饰品与小屋/宠物放大"
git push origin main           # 弹窗登录：用户名填 GitHub 用户名，密码填 Token
```

推送后刷新 <https://chillsann.github.io/pet-adventure/> 即可玩到新版。

**开 GitHub Pages 让孩子直接玩**：仓库 Settings → Pages → Source 选 `main` 分支根目录，保存。
之后浏览器访问 `https://<你的用户名>.github.io/pet-adventure/` 即玩，手机也能开。
