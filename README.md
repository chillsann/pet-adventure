# 🐾 宠物大冒险 · Pet Adventure

汪汪队（PAW Patrol）风格的横版跑酷小游戏，单文件 Canvas 实现，无任何外部依赖。

## 🎮 试玩
https://chillsann.github.io/pet-adventure/

## ✨ 特色
- 🐱 9 只手绘 Q 版宠物（橘猫 / 柴犬 / 兔子 / 熊猫 / 小熊 / 青蛙 / 狐狸 / 企鹅 / 龙宝）
- 🛵 5 种手绘载具（电动车 / 单车 / 滑板车 / 滑板 / 雪橇）
- 🏞️ 6 大主题关卡循环（草原 / 沙漠 / 冰雪 / 糖果 / 火山 / 霓虹）
- ⭐ 收集星星与礼物盒，解锁新宠物
- ❤️ 3 命 + 检查点 + 看广告复活（Web 模拟）
- 📱 键盘 + 触屏双操作

## 🕹️ 操作
- **← → / A D**：移动
- **空格 / ↑ / W**：跳跃
- **Esc / P**：暂停
- 手机：屏幕虚拟按键

## 🛠️ 技术
- 单 HTML 文件，Canvas 2D 手绘全部图形（动物 / 载具 / UI / 特效零 emoji 依赖）
- 固定 60Hz 物理循环，横屏适配，localStorage 存档
